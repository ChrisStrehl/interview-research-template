# companies/

One folder per researched company, created by `/research`. The template ships this folder empty.

```
companies/<slug>/
  inputs/            what you gave it: job description, transcripts, links, your notes
  evidence/          raw material per front. You do not read this; it is there for depth and citations
  research/          one summary per front, fixed headings, every claim graded
  product/           product map, onboarding teardown, screenshots in product/screens/
  frameworks/        lean canvas, AARRR, SWOT, and whatever you add later
  claims-register.md the load-bearing claims, their grade, and what would verify each
  point-of-view.md   the read: what it is, how it is doing, strengths, weaknesses, focus, hypotheses
  index.md           the one-page entry point
  site/index.html    the rendered walkthrough for screen-sharing
  state.json         what has run, when, and what is stale
```
